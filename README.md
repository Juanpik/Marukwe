# Marʉkwe! 

**Plataforma Interactiva para el Aprendizaje de la Lengua Comanche (*Nʉmʉ Tekwapʉ̲* / *Nʉmʉ Rʉkwepʉ̲*)**

---

## 📖 Acerca del Proyecto

**Marʉkwe** es una aplicación web interactiva diseñada para apoyar la revitalización, el aprendizaje y la difusión de la lengua comanche (*Nʉmʉ Tekwapʉ̲*). 

Perteneciente a la rama númica de la familia lingüística **yuto-azteca**, la lengua comanche posee una profunda riqueza cultural e histórica vinculada a los pueblos originarios de las Grandes Llanuras y el norte de México.

Esta plataforma ofrece una experiencia accesible, visual y lúdica que reúne 172 términos organizados por campos semánticos con ilustraciones de contorno táctil continuo y actividades pedagógicas interactivas.

---

## 🎯 Características Principales

- **Diccionario Ilustrado (Léxico)**: 
  - 172 vocablos clasificados por campos semánticos (animales, naturaleza, cuerpo humano, objetos cotidianos, alimentos, etc.).
  - Contorno vectorial continuo animado (*delineado táctil*) para cada elemento.
  - Caracteres ortográficos comanches estandarizados (`ʉ`, saltillo `ʔ`, vocales largas y subrayadas).
- **Módulo de Repaso Dinámico**: Selección de palabras personalizadas antes de jugar o practicar.
- **Actividades Interactivas**:
  - 🧩 **Crucigrama**: Generación procedural adaptativa de crucigramas con pistas visuales y textuales.
  - 🔍 **Sopa de letras**: Tableros dinámicos en diferentes niveles de dificultad.
  - 🃏 **Memorama**: Emparejamiento interactivo de imágenes con vocablos comanches.
  - 💡 **Adivinanzas de palabras**: Desafío guiado de identificación léxica.
  - 🗂️ **Tarjetas de estudio (Flashcards)**: Tarjetas con volteo animado para autoestudio.
  - 📝 **Cuestionario (Quiz)**: Evaluación de opción múltiple con retroalimentación inmediata.
- **Diseño Adaptativo (Mobile-First)**: Optimizado para smartphones, tablets y pantallas de escritorio.

## 🚀 Instalación y Uso Local

La aplicación está construida con tecnologías web estándar (HTML5, CSS3, JavaScript Vanilla), por lo que no requiere compilación previa.

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Juanpik/Marukwe.git
   cd Marukwe
   ```

2. Inicia un servidor web local (por ejemplo con Python):
   ```bash
   python -m http.server 8080
   ```

3. Abre en tu navegador preferido:
   ```
   http://localhost:8080
   ```
